Chapter 1 Option 1B: Ransomware Attack IR Playbook

Structured 6-Phase NIST Incident Response Lifecycle Flowchart & Decision Assessment

Playbook Readiness Score: 0 / 6 Completed
PHASE 1 Preparation
Actionable Technical & Administrative Procedures:
  • Maintain immutable, air-gapped offline backups and test restoration monthly.
  • Deploy Endpoint Detection & Response (EDR) across all workstations and servers.
  • Enforce Multi-Factor Authentication (MFA) on VPNs and corporate remote access points.
PHASE 2 Detection
Actionable Technical & Administrative Procedures:
  • EDR triggers automated alert on mass file modification and shadow copy deletion (vssadmin).
  • SIEM flags suspicious lateral movement via anomalous PowerShell/SMB network traffic.
  • Help desk receives initial user tickets regarding .locked file extensions and ransom notes.
PHASE 3 Analysis
Actionable Technical & Administrative Procedures:
  • Identify ransomware strain variant and locate initial compromise vector (e.g., VPN credential theft).
  • Determine scope of encryption and check for exfiltrated sensitive data (double extortion).
  • Classify incident severity level and activate CSIRT Core Team + Legal/PR stakeholders.
PHASE 4 Containment
Actionable Technical & Administrative Procedures:
  • Isolate infected hosts at network level via switch port shutdown or EDR isolation.
  • Disable compromised Active Directory domain accounts and revoke active API/session tokens.
  • Block known command-and-control (C2) IP addresses and malicious domains at the perimeter firewall.
PHASE 5 Eradication & Recovery
Actionable Technical & Administrative Procedures:
  • Terminate malicious persistence mechanisms (scheduled tasks, registry run keys, web shells).
  • Rebuild compromised systems from known-clean golden images and patch root vulnerability.
  • Restore business data from validated offline backups and monitor network for re-infection signals.
PHASE 6 Post-Incident Activity
Actionable Technical & Administrative Procedures:
  • Conduct formal "Lessons Learned" meeting within 72 hours of incident closure.
  • Document complete timeline, root cause analysis, and attacker indicators of compromise (IOCs).
  • Update IR playbooks, patch system gaps, and adjust SIEM/EDR detection rules.
